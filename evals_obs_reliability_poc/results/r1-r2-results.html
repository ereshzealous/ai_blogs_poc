Re-run it yourself

From the chapter folder. None of these commands changes the published run; `make verify` and `make test` write their own reports (the verification files), which is how they report.

make setup
the POC environment (Python 3.12 via uv; pytest)
make test
the POC's unit and end-to-end tests (real processes, no model) -> verification/pytest.*
make verify
PROOF VERIFICATION of the published run -> evidence/verification/verification.{txt,json}
make replay
every deterministic experiment re-executed in a temp folder and compared with the published run (nothing recorded)
make demo
the flagship (S09) through the naive and the classified runtime, explained step by step
make docs
both editions and the three evidence documents as Markdown, standalone HTML and PDF
make qa
rendered checks of every page (desktop/tablet/mobile) and the Lab Console -> qa/
