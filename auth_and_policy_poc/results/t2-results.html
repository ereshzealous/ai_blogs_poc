Re-run it yourself

From the chapter folder. None of these commands changes the published run; `make verify` and `make test` write their own reports (the verification files), which is how they report.

make setup
nothing to install: authz_poc uses the Python standard library (the docs build uses uv)
make test
the four test layers, L1 to L4 (L4 replays the run into a temp folder)
make verify
PROOF VERIFICATION: the deterministic run re-executed in a throwaway copy, byte for byte against the published run
make replay
the deterministic run re-executed in a throwaway copy of the POC and compared byte for byte with the published run
make demo
no single-scenario demo here: make replay re-executes the whole recorded run
make docs
both editions as standalone HTML, the Medium image kit, then the uniform series pages
make qa
the Medium edition's checks: what Medium cannot show, relative links, stale wording
